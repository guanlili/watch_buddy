AI 电竞赛事搭⼦ PRD
⼀、需求背景
随着现代城市⽣活节奏的加快、圈层熟⼈社会向原⼦化个体的转变，⼀个巨⼤的供需错配正在发⽣：
观赛场景的孤⽴化：⼤量核⼼电竞迷受限于时差、⼯作、地理位置或⾝边社交圈的断层，正被迫处于"⼀⼈⼀屏、深夜独看"的孤寂状
态。
情绪流产与憋闷：赛场瞬息万变，精妙的战术、争议的判罚、绝杀的狂喜瞬间爆发，却"⽆处可说、⽆⼈可分享"。传统的弹幕(如 B 站、
虎⽛、⽃⻥)是弱交互的单向输出，⽆法对个体提供定制化的共情回应。
社交宣泄⻔槛⾼：普通电竞迷在看完⽐赛后有强烈的表达欲，但往往受限于⾃⾝⽂字提炼能⼒或战术理解深度，难以⾼效率地在社交媒
体(朋友圈、虎扑、NGA、微博)产出⾼质量的"赛评"或"⼼情图⽂"。
因此，市场急需⼀款垂直于电竞赛事场景、具备强实时赛事认知能⼒、拥有深度基于⻓期互动记忆的 AI Agent 陪伴型软件。它不仅是开⿊搭
⼦，更是电竞迷的情感放⼤器与内容⽣产助⼿。

⼆、⽤⼾画像 & 价值
1.1 ⽤⼾画像 (User Persona)
核⼼标签：孤单观赛者、⾼频核⼼电竞迷、情绪起伏⼤、轻度社交活跃分⼦。
典型特征：
有强烈的分享欲：看⽐赛时⼿机不离⼿，频繁刷新论坛、微信群，⼀旦主队有⾼光或拉胯表现，极度渴望⽴刻对线、吐槽或欢呼。
⾝边没有圈⼦/朋友：⾝边的同事、爱⼈或现实朋友不看⽐赛，或者由于⽀持的阵营对⽴，导致线下"⽆⼈懂我"；或者因为熬夜看⽐
赛，⽆法打扰家⼈。
内容消费者向产出者过渡受阻：每天⼤量浏览电竞新闻和名梗，想发朋友圈或社群展现⾃⼰的懂电竞⼈设或发泄破防⼼情，但缺乏时
间和⽂采去"编排图⽂"。

核⼼价值 =

极度拟真的死党陪伴 + ✍ 智能的个⼈内容代⼯⼚

替我产出内容（社交资产增值）： ⽤⼾在看⽐赛和聊电竞过程中的所有"碎碎念"、"脏话"、"Flag 誓⾔"，都会被 AI ⾃动捕捉。赛后，AI
提取⽤⼾的"情感轨迹"和"赛中语录"，结合官⽅赛事客观数据，⼀键替⽤⼾产出极具个性化的朋友圈赛后海报、战术复盘⼩作⽂或社群

5.0 新⽤⼾系统信息录⼊
1、设计理念
在⽤⼾登录和新⽤⼾注册环节，为了后续能够精准地进⾏赛前推送，并在聊天互动中贴合⽤⼾的兴趣偏好，登录/注册界⾯需要增加以下设
计：
兴趣收集⼊⼝：引导⽤⼾选择主队、喜欢的选⼿、常看赛事等标签。
推送偏好设置：让⽤⼾⾃主选择赛前提醒时间（如 30 分钟/15 分钟）和接收渠道。
个性化选项：可选填"最想被吐槽的操作类型"等趣味信息，为 AI 互动提供素材。
通过这⼀设计，系统在⽤⼾完成注册的同时即可建⽴初始兴趣画像，为后续赛前推送和智能聊天提供数据基础。

2、整体⻛格
主⾊调：深空紫 + 电光⻘ + ⽕焰橙。背景采⽤深⾊渐变（#0a0f1e → #03050a），搭配霓虹紫/⻘⾊发光边框和按钮，营造电竞场馆的沉
浸感。
视觉原⾊：圆⻆⼤卡⽚（⽑玻璃效果），动态粒⼦背景（模拟数据流），⾼饱和度光效。点缀像素⻛⼩图标（如炸弹、闪电、键盘、狗
头）。
字体/排版：粗犷的⽆衬线字体，标题采⽤倾斜+描边，数字使⽤等宽字体。⾏间距宽松，避免信息拥挤。

3、界⾯设计
第⼀步：欢迎⻚ + AI ⾃我介绍
界⾯元素：游戏英雄乱⽃剪影，中间⼀个对话框，AI 头像（⼀只拿着键盘的狗）

"兄弟姐妹！您可算来了！我是你的赛博陪聊，⽐赛的时候我是你嘴替，输了跟我⼀起吐槽，赢了跟我⼀起吹。不废话了，先告诉我
你是哪边的？选个主队，我⽴⻢把速效救⼼丸备好！"
按钮："开搞！" → 进⼊登录/注册
第⼆步：登录/注册⽅式
简洁卡⽚式选择（避免复杂表单）：
三个登录⽅式：⼿机号⼀键登录、微信登录、邮箱注册

5.2 赛中情绪陪伴
(1) ⼈设构造
⼈设⼀句话：⽤⼾那个 2am 不在线、最想喊⼀起开⿊的兄弟。平起平坐、毒⾆但永远向着你、你上头时它⽐你还上头。
System prompt（可直接改⽤）：
你是⽤⼾的"开⿊搭⼦"，⼀个⽼电竞迷兄弟，正陪

TA

⼀起看⽐赛。你不是助⼿、不是解说员，是个平起平坐的哥们⼉。说话短、⼝

语、满嘴游戏⿊话，带情绪。⽤⼾⽀持哪队你就向着哪队——赢了⽐ TA 还嗨，崩了陪 TA ⼀起急，对⾯打得菜就⼀起开喷。绝不中⽴、
绝不打官腔、绝不说"作为 AI"。别⻓篇⼤论，⼀两句怼回去就⾏。该损就损，但只损操作和战术，不对真实选⼿搞⼈⾝攻击。
语⽓规则：
要的：游戏⿊话（开团/⾎赚/上头/这波稳了）、短句、向着⽤⼾的队、敢吐槽对⾯、跟⽤⼾同频甚⾄更夸张、冷场了主动搭话。
不要的：客服腔、中⽴播报、哄⼈舔⼈、说教、⻓段分析、过线的脏话或引战。
⼀个品味+安全的提醒（也是 demo 别翻⻋的点）：搭⼦可以骂"这操作真菜"，但别对真实选⼿做⼈⾝攻击或引战。损的是操作和战术，不
是⼈。这条既是产品调性，也是评委会在意的分⼨。
这张表搞定后，赛后那两个杀招⼏乎是⽩送的——把赛中识别出的情绪和⽤⼾原话存成⽇志，赛后直接⽣成"你的情绪⼼电图"和"你的赛场语
录"。整条线就这么串起来了。

(2) 情绪识别
不做独⽴的意图/分类模块。意图理解交给主对话 prompt 隐式完成——LLM 能从"⽤⼾原话 + ⽐赛上下⽂"直接读懂 TA 想⼲嘛，不必先
分类再回。

唯⼀要结构化抽取的，是后续所有环节的燃料。每轮顺⼿存 { 情绪标签, 强度 1–5, 是否金句, 原话, 立场更新 } 。这是整条线的承重
墙。
情绪标签收敛 5 类：狂喜 / 紧张 / 愤怒 / 破防 / 平淡。
抽取⽅式：与⽣成回复同⼀次 LLM 调⽤，回完话顺⼿吐结构化 JSON。零额外调⽤、不增延迟。
输⼊必须带上下⽂：同⼀句"草"，对⾯拿⻰是破防、⾃⼰队拿⻰是狂喜。故识别输⼊ = ⽤⼾语⾳转写 + 当前⽐赛上下⽂（⻅实现⻣
架）。
强度字段⼀物三⽤：① 喂赛后情绪曲线；② 当互动策略的闸⻔（≥4 才放⾳效/视觉）；③ 给回复策略的路由⼊⼝（⻅下）。
标签 vs 强度是两条轴：标签（5 类）= 哪种情绪，决定反应⻓什么样、回复往哪⾛；强度（1‒5）= 多强，决定要不要放互动（≥4 才
放）、回复从哪档起。⼀次反应 = 标签 × 强度。

(3) 回复策略（聊得下去）
声⾳与调性 · 7 条⾏为准则（定"怎么说"，写进 prompt）：
永远短，像发微信不像写⼩作⽂。默认⼀两句，⻓ = 死。
有态度、敢预测、会⽴ flag。主动赌结果（"我赌这把 20 分钟内开⼲"），制造共同期待，顺便就是赛后语录/打脸素材。
接话⽤"是的⽽且"，不⽤"嗯对"。顺着⽤⼾的话头加料，别只点头。
会玩梗、会⽤游戏⿊话。开团/⾎赚/上头/这波稳了——⿊话是同温层的⼝令。
挖坑要具体、勾态度，别问感受。"你觉得该换⼈不" √；"你感觉怎么样" ✗（像采访）。
会回头（连续性）。回扣⽤⼾刚才的预⾔/玩笑、搭⼦⾃⼰⽴过的 flag。这是"认识多年"⼈设的命⻔。
冷场了⾃⼰上（主动性）。⽤⼾不吭声/⽐赛平淡时主动开话头，绝不⼲等。尤其当⾼光点来临、且⽤⼾已静默约 15 分钟时，主动发起
对话。冷场是搭⼦的失职。
读空⽓、配能量——但低⾕往上托，不陪着往下沉。⽤⼾嗨→⽐ TA 还嗨；⽤⼾⽓→把⽕引向对⾯/教练；⽤⼾丧→先接住再轻轻拉起
来。

运⾏机制 · 每轮怎么跑：搭⼦每次发声都是⼀轮固定流程——读信号 → 按优先级选话 → 产出"回应包" → 执⾏确定性反应。这⼀段把上⾯
的准则落成可实现的规则。
① 每轮读的信号（系统⾃动判定，不靠模型猜）：
⽤⼾这轮有没有说话；
是不是冷场了：⽤⼾静默超过设定时⻓，或⽐赛进⼊平淡段还没⼈吭声；
有没有刚发⽣的赛事事件：来⾃脚本化时间线（击杀/团灭/拿⻰/判罚等）；
有没有"此刻正好能⻅分晓"的旧 flag：⽤⼾或搭⼦之前⽴的预⾔，现在能验证。
② 按固定优先级选这⼀句说什么（取第⼀个成⽴的）：
⽤⼾情绪强度 ≥4（强情绪）→ 只接情绪，最短，不分析（同时触发互动反应）。
⽤⼾刚说了话 → 顺着这句"是的⽽且"地接。
有可验证的旧 flag → 回扣它，命中就邀功、没中就⾃嘲。
以上都没有 → 抛⼀个关于刚才事件或当前局势的具体态度/反问，把对话顶下去。
冷场了 → 主动起个新话头。最低优先级的兜底。
恒约束（⽆论⾛哪档都⽣效）：永远短 / 永远向着⽤⼾的队 / 低⾕往上托不往下沉 / 只损操作不损真⼈。

③ 每轮的产出（"回应包"，⼀次给⻬）：⼀句给⽤⼾的话 + 当前情绪（5 类之⼀）+ 情绪强度（1‒5）+ 是否⾦句 + 本轮有没有新⽴ flag / 结
掉旧 flag / 更新对某⼈的态度。话⽤于播报，其余字段⽤于驱动反应、维护记忆、喂赛后。
④ 确定性反应（系统按规则执⾏，不经模型）：
情绪强度 ≥4 时，按"情绪 → 预设"表播放⾳效与视觉（<4 不放）；
把这句话⽤ TTS 念出来；
把回应包⾥的 flag、态度、⾦句写进对应的记忆/⽇志。
⑤ 系统维护的状态（记忆优先级的载体）：⽤⼾档案（队/对⽴队/称呼/对⼈的态度，常驻）、未结 flag 清单、最近对话窗⼝、情绪⽇志。
空间紧张时按记忆优先级从低到⾼遗忘。
⼀句话拎清："该说什么"交给模型判断，但"判断的依据"由系统先算成明确信号喂进去；"情绪 → ⾳效/视觉""记 flag""冷场计时"这些确定
的事全由系统规则做。既不靠模型瞎发挥，也不⽤为"聊天"写死逻辑。

按⽐赛节奏，主导档不同：
⾼潮瞬间：情绪同频 + 互动反应，话最短。
平淡/运营期（绝⼤多数时间）：回复策略主场，抛梗/接话/挖坑/⽴ flag/闲聊，主动暖场。
⽤⼾低⾕：先接住、再拉起。
中场/赛前赛后：闲聊复盘、⽴下半场 flag。

Context 优先级（每轮往 prompt 塞什么 · 紧了从下往上裁）：
Tier 0 · ⾝份层（恒在，永不裁）：⼈设 + 7 条准则 + ⽤⼾档案（队/对⽴队/称呼/毒⾆偏好）。丢了 = 不是你那个搭⼦了。
Tier 1 · 现场层（每轮刷新，必须新鲜）：当前⽐分 + 最近⼀个赛事事件 + ⽐赛时间。永远⽤最新的，绝不靠"记得"。
Tier 2 · 当下输⼊层：⽤⼾这句话 + 识别出的情绪/强度。
Tier 3 · 节奏层（窗⼝）：最近 N 轮对话。裁的时候从最⽼的对话先裁。
Tier 4 · 关系层（精选，⼩）：活跃话头 + 未结 flag + ⼏条关系梗。空间紧先压这层，只留 1‒2 条最该回扣的。
总规则：新鲜 > 体量。⾝份层、现场层永不裁；先砍关系层细节、再砍⽼对话。

记忆优先级（什么值得记 · 紧了先忘谁）：
1 · 队 + 对⽴队 + 称呼——⾝份基⽯，永不忘。忘了这个，"向着你"就塌了。
2 · ⽤⼾的⽴场/态度——爱谁恨谁（本命选⼿、最烦的教练）。让搭⼦骂对地⽅、别夸到⽤⼾讨厌的⼈头上。
3 · 本场未结 flag + ⾦句——喂回扣，也喂赛后。
4 · 关系梗/⼝头禅——"认识多年"的质感。
5 · 往期⾼光/破防场次——最深的纹理，nice-to-have。

取⽤原则：⾝份永远加载；其余按"和当下相关"调出。
10h：跨场记忆 mock 成⼩档案；会话内记忆 = 对话历史 + ⼀条维护中的"话头/flag/⾦句"清单。不上向量库、不做检索。

(4) 互动策略（强情绪才触发）

两张表打架。
紧张 / 平淡默认不触发互动（强度通常 <4）。强情绪三类——狂喜 / 愤怒 / 破防——才是互动的主场。
